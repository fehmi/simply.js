Props

Values passed as attributes on a component tag become props in the child — reactive, typed, and accessible in template, style, and script. Complex objects are passed via simply.objToPropString() wrapped in single quotes.

String / Number / Boolean

Inline attributes: title="..." count="..." enabled="..." message="..."

Object via simply.objToPropString

Theme: {{data.settings.theme}} · Items: {{data.settings.items.join(", ")}}

Passed as settings='{{"{{"}}simply.objToPropString(data.settings){{"}}"}}' — single quotes are required for objects/arrays.

Notes

  • props.title — read a prop in template or script; overridden by props = { ... } in the child class if defined.
  • Any type works: String, Number, Boolean, Object, Array, even Function.
  • Changing the parent's data.* re-renders the child with the new prop values — fully reactive.
